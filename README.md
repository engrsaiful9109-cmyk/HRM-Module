# 🏢 MEP Group — HRM Online (Flat Single-Folder Edition)

এই ফোল্ডারে **কোনো সাবফোল্ডার (js, data, assets) নেই**!
সবগুলো ফাইল (মোট ২২টি) একই লেভেলে পাশাপাশি সাজানো আছে।

---

## 🚀 GitHub ওয়েবসাইট থেকে ১-ক্লিকে আপলোড করার নিয়ম:

1. [github.com](https://github.com)-এ একটি নতুন Public Repository তৈরি করুন (যেমন: `mep-hrm`).
2. পেজে **"uploading an existing file"** এ ক্লিক করুন।
3. এই ফোল্ডারের ভেতরে ঢুকে কিবোর্ডে চাপুন: **Ctrl + A** (সব ফাইল একসাথে সিলেক্ট হবে)।
4. মাউস দিয়ে ড্র্যাগ করে গিটহাবের আপলোড বক্সে ছেড়ে দিন (অথবা **"choose your files"** বাটনে ক্লিক করেও সব ফাইল একসাথে সিলেক্ট করতে পারেন!)।
5. নিচে সবুজ **"Commit changes"** বাটনে ক্লিক করুন।
6. **Settings -> Pages** এ গিয়ে Branch হিসেবে **`main`** সিলেক্ট করে Save করুন।

ব্যস! ১ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে এবং ফায়ারবেসের সাথে রিয়েল-টাইমে সিঙ্ক থাকবে!
